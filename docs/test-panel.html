panel.js — print panel / cut sheet test

Four styles, four different paint setups, exercising renderCutSheet, cutSheetPieces and seamStraddleWarnings together. LS uses a demo <pattern> passed through defs with slots.all (full all-over print). SS uses named slots only, in flat colours, with every slot painted. Shorts uses named slots with only some pieces painted (to show warnings firing selectively). Spats uses two different named colours on the two leg pieces (mismatched sides).
