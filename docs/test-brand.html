01 — Palette

Core tokens

Ink Navy ground, Bone White lockup, Prodigy Gold as the single hot accent, three neutrals, plus a light page surface and a near-black footer ground.

Belt colours — rank system, not brand chrome

A separate, locked semantic system encoding rank (white / blue / purple / brown / black). Never spent on marketing chrome. Purple reads differently under different lighting and screens; #5B2C8F is pinned here as a defensible mid-tone rather than left to drift per-component.

02 — Type

Scale

Display face (headings, buttons, badges): 'Barlow Condensed', 'Arial Narrow', Impact, 'Segoe UI', system-ui, sans-serif, uppercase, tight tracking. Body/UI face: Barlow, 'Segoe UI', system-ui, sans-serif. No external fonts — this is the system-stack fallback rendering, exactly as it will degrade everywhere.

Body copy

Barlow, or its system fallback, set at --fs-base with --leading-base line height. A practitioner-craft, technical-sportswear read — not tribal, not flames, not blackletter. Muted text uses var(--muted), which resolves differently per surface (see the contrast table below).

04 — Marks

Monogram / badge

Original mark — the client has no logo, this is a proposal. A bold "P" whose bowl is cut as an angular, faceted loop: reads as a cinched grappling-belt knot without going tribal / flames / blackletter. Two flat shapes, no gradients, no thin strokes — built to survive small embroidery and heavy sublimation. assets/logo.svg and assets/favicon.svg are the identical badge.

currentColor variant

The mark path uses fill="currentColor"; the SVG's own color="#E8A33D" is a low-specificity presentation attribute, so an inlined instance can be recoloured with real CSS. Backing plate stays Ink Navy in both.

Wordmark

Horizontal lockup, rectilinear block-stencil letterforms drawn as <path> geometry — no <text>, no font dependency.

Default — Bone White on Ink Navy (the primary lockup colour per docs/DESIGN.md).

Recoloured via CSS to Ink Navy for use on a light surface (same file, inlined).
